# Pomodoro for Minimide

A focus timer in the status bar: 25 minutes of work, 5 of rest. Click it, or press
`Mod-Alt-T`, to start and pause. Set the lengths in **Settings → Packages → Pomodoro**.

Install in Minimide with **Packages: Install Package…** → `mikemich/minimide-pomodoro`,
or find it in **Settings → Packages → Discover**. It runs sandboxed and asks for no
permissions.
